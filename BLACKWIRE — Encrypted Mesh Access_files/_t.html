WHY THE MESH

Built for the parts of the internet that watch back

◈

Zero-log relays

Every node runs in RAM only. Nothing about your session ever touches a disk, so there's nothing to seize.

⬡

Onion-routed circuits

Rotating exit nodes

QUESTIONS

Before you connect

Can BLACKWIRE see my traffic?+
No. Each relay only knows the hop before and after it — never the full path, and never the content, since everything is encrypted end to end before it enters the mesh.
What happens if a relay is seized?+
Nothing useful is on it. Relays run entirely in memory with no persistent storage, so there are no logs, keys, or session data to recover.
Does the kill switch slow down my connection?+
It adds no measurable overhead. It's a local firewall rule that drops traffic instantly if the tunnel disconnects — it only activates during a fault.
Can I run my own relay node?+
Yes. The mesh is community-operated — anyone can run a node with the open client. Verified operators get a share of network fees.
